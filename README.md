# Alpha Core AUV

This repository contains source codes for ALPHA AUV family.
**This repo is replaced by two other repositories for better management**
- [`mvp_core`](https://github.com/GSO-soslab/mvp_core): a collection of drivers for hardware devices
- [`mvp_utilities`](https://github.com/GSO-soslab/mvp_utilities): a collection of nodes for data handling
